# ============================================================================
#  PMSI SMR — dictionnaire des synonymes de la recherche d'actes CSAR
# ============================================================================
#
#  Une ligne par entrée :
#
#      terme saisi, autre terme saisi = terme du catalogue | autre possibilité
#
#  - À GAUCHE du signe égal : ce que l'on tape, termes séparés par des virgules.
#  - À DROITE : ce qu'il faut chercher dans les libellés du CSAR. La barre
#    verticale sépare plusieurs possibilités, une seule suffit ; les actes
#    répondant à la première sont classés en tête. Dans une possibilité de
#    plusieurs mots, tous doivent être présents.
#  - Le terme de droite peut être un code d'acte :  standing = 07S12
#  - Accents, majuscules et petits mots (de, du, la, à…) sont ignorés.
#  - Ce qui suit un # est un commentaire.
#
#  Le mot saisi reste toujours cherché tel quel, en plus de ses synonymes. Un
#  mot d'au moins quatre lettres vaut début de terme : « reeduc » retrouve
#  « rééducation ». Une abréviation de trois lettres ou moins (MS, MI, FRE)
#  n'est reconnue qu'en entier.
#
#  Ce fichier est REMPLACÉ à chaque mise à jour de l'outil. Vos ajouts
#  personnels vont dans  ~/.dim/smr_synonymes_csar.txt  (même syntaxe, fichier
#  à créer) : il s'ajoute à celui-ci et survit aux mises à jour.
#
#  Une modification est prise en compte dès la recherche suivante, sans
#  relancer l'application.
#
#  Le dictionnaire traduit du VOCABULAIRE, pas des indications : on n'y trouve
#  ni diagnostics (AVC, BPCO, prothèse de hanche) ni métiers.
# ============================================================================
